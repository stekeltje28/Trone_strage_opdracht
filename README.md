# 🐾 Pet Sitting App – Stageproject

Een eenvoudige maar complete pet-sitting applicatie gebouwd voor mijn stage-opdracht.  
De app heeft een **FastAPI-backend** en een **statische frontend** met HTML, CSS en JavaScript.

---

## 💡 Wat doet het?
Met deze applicatie kun je:
- Huisdieren toevoegen, bewerken, verwijderen en bekijken  
- (Bonus) afspraken plannen voor pet-sitting  
- (Optioneel) inloggen en registreren via een eenvoudige auth-module

---

## 🧱 Technische stack
**Backend**
- Python 3.12  
- FastAPI + SQLModel (met SQLite-database)  
- JWT-authenticatie  
- Docker-ready

**Frontend**
- Eenvoudige HTML/CSS/JS site  
- Wordt geserveerd via Nginx (in Docker)
